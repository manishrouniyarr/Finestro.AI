# Finestro.AI - Advanced MERN Finance SaaS Platform

Finestro.AI is a full-stack finance management application built with the MERN stack. It provides users with a secure and intelligent way to manage transactions, track expenses, and gain insights through advanced analytics and AI-powered features.

## Key Features

- Authentication with Email and Password (JWT)
- Create, Edit, and Manage Transactions
- Upload and Scan Receipts using AI
- Advanced Analytics with MongoDB Aggregate Pipeline
- Expense Breakdown with Pie Charts
- Income and Expense Tracking with Line Charts
- Filter Transactions by Date Ranges (e.g., Last 30 Days)
- Recurring Transactions using Cron Jobs
- Auto-Generated Monthly Reports (Emailed to Users)
- CSV Transaction Import
- Search and Filter Transactions
- Pagination Support
- Bulk Delete and Duplicate Transactions
- Profile Photo Upload (Cloudinary)
- Built with MERN Stack: Node.js, MongoDB, React, TypeScript
